# DailyTrack – To-Do List App

A simple and interactive To-Do List application built with **HTML, CSS, and JavaScript** to practice and strengthen front-end development skills.

## Features
- Add, complete, and delete tasks.
- Search and filter tasks.
- Track pending and completed tasks.
- Light and Dark mode.
- Task statistics.

## Technologies
- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Run `index.html` in your browser.

## Purpose

Developed as a personal practice project to improve JavaScript, DOM manipulation, and front-end development skills.
